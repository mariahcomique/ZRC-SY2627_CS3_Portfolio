## 2. If you were to add a new role called Intern, where would you place it in the inheritance hierarchy? Why?
If I were to add a new role called Intern, I'd place it after the employee class. Since the Employee class is inherited from the Person class, the Intern class would inherit both the Employee class and Person class.
